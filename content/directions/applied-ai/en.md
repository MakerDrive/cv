## What I work on

I build tools and workflows in which AI agents work with project context and pass tasks between executors. These systems support research, development, and result review while preserving the state of ongoing work.

## Projects

| Project | Example |
| --- | --- |
| [Agent Portal](../../projects/agent-portal/) | An engineering workspace with resource groups, model routing, and an executable Kanban board. |
| [Agent Pool MCP](../../projects/agent-pool-mcp/) | Delegation to CLI agents with visible ownership and execution state. |
| [Project Graph MCP](../../projects/project-graph-mcp/) | Tools that give agents a structured view of a codebase and its dependencies. |
| [Symbiote Workspace](../../projects/symbiote-workspace/) | A task-specific workspace assembled from a portable configuration. |
| [Browser X MCP](../../projects/browser-x-mcp/) | An early Playwright browser tool for controlled UI operations. |

## My contribution

In Agent Portal, I designed resource groups and task-placement rules. They match process stages with available models and limits. In Agent Pool, I developed the delegation path for CLI tasks: a call returns an identifier that can be used to follow execution and retrieve its result. Acceptance remains with the calling process.

Project Graph MCP produces a compact representation of a codebase for an agent. Symbiote Workspace assembles an interface for a specific task from a validated configuration. Together, these projects show how context, tools, and execution can work as one process.

## Boundaries and ongoing work
