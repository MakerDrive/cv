## En qué trabajo

Desarrollo herramientas y procesos en los que los agentes de IA trabajan con contexto de proyecto y pasan tareas entre ejecutores. Estos sistemas sirven para investigación, desarrollo y revisión de resultados, conservando el estado del trabajo en curso.

## Proyectos

| Proyecto | Ejemplo |
| --- | --- |
| [Agent Portal](/cv/projects/agent-portal/) | Entorno de ingeniería con grupos de recursos, enrutamiento de modelos y un tablero Kanban ejecutable. |
| [Agent Pool MCP](/cv/projects/agent-pool-mcp/) | Delegación a agentes CLI con responsabilidad y estado de ejecución visibles. |
| [Project Graph MCP](/cv/projects/project-graph-mcp/) | Herramientas que ofrecen a los agentes una vista estructurada del código y sus dependencias. |
| [Symbiote Workspace](/cv/projects/symbiote-workspace/) | Un espacio de trabajo para una tarea concreta, ensamblado desde una configuración portátil. |
| [Browser X MCP](/cv/projects/browser-x-mcp/) | Una primera herramienta de navegador con Playwright para operaciones de UI controladas. |

## Mi contribución

En Agent Portal diseñé los grupos de recursos y las reglas para asignar tareas. Relacionan cada etapa del proceso con los modelos y límites disponibles. En Agent Pool desarrollé la delegación de tareas CLI: una llamada devuelve un identificador que permite seguir la ejecución y obtener el resultado. La aceptación corresponde al proceso que solicitó el trabajo.

Project Graph MCP genera una representación compacta del código para un agente. Symbiote Workspace ensambla una interfaz para una tarea concreta a partir de una configuración validada. En conjunto, estos proyectos muestran cómo conectar contexto, herramientas y ejecución en un mismo proceso.

## Límites y trabajo en curso

Agent Portal incluye grupos de recursos y enrutamiento de modelos. Las opciones de despliegue y el tratamiento de datos sensibles dependen de la configuración y la integración; un esquema por sí solo no ofrece privacidad.
