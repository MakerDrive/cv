# Adaptive Maximo Workbench

:::article-block demo-alpha
Adaptive Maximo Workbench is a Demo / Alpha configuration used to test Symbiote Workspace in an enterprise maintenance domain. It demonstrates the workspace architecture; connecting a production Maximo system is separate integration work.

:::article-block work-order-demo
The accepted demo path is read-only: open a work order, inspect its linked asset, and review the declared action list.

:::article-block work-orders
The work-order surface keeps the queue, status, priority, and related operational context visible in one place.

:::article-block asset-context
Asset and location context stays linked to the selected work order, so a person and an agent can inspect the same current information.

:::article-block safe-actions
The interface declares the actions available in the current state. Any operation that could change an external system remains unavailable in this public demo.

:::article-block integration-boundary
Production data, authentication, authorization, and Maximo API calls belong to a separate host-owned integration layer.
