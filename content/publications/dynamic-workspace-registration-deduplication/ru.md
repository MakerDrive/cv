Во время MCP initialization Agent Portal читает workspace roots клиента и регистрирует каждый root как проект в StateGraph. Проект открывается как dashboard tab и становится доступен общему backend, к которому подключены окна IDE.

StateGraph дедуплицирует проекты по сохранённой строке пути. Повторная регистрация того же пути обновляет существующую запись и время последнего открытия. Текущая реализация не канонизирует путь через `realpath`, не вычисляет hash и не объединяет варианты регистра. Поэтому symlink aliases и разное написание пути могут создать отдельные записи.

Реализованный код после поиска точного пути выдаёт короткий случайный project ID и сохраняет состояние через StateGraph. Project identity не выводится из SHA-256, а benchmark времени регистрации в репозитории не зафиксирован. Качество дедупликации зависит от path identity, переданного MCP-клиентом.
