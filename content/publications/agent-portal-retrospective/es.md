Agent Portal se convirtió en el punto de entrada público de mi línea de herramientas para agentes. Una sola configuración MCP expone las operaciones del portal y un conjunto seleccionado de herramientas hijas. El runtime de ejecución queda detrás de ese límite, mientras el dashboard muestra chats, workflows, estructura del proyecto, estado de tareas y diagnósticos en vivo desde el mismo backend.

El runtime utiliza un backend singleton desacoplado para atender varias ventanas del IDE. Cada cliente local arranca mediante stdio y se conecta al backend por WebSocket; el backend mantiene los procesos MCP hijos y el estado compartido del portal. Los modos standalone, client y master amplían el mismo contrato a conjuntos de herramientas locales o remotos.

El trabajo de StateGraph añadió operaciones versionadas. Un navegador que se reconecta con una versión conocida recibe los patches pendientes si todavía están disponibles; un cliente demasiado antiguo recibe un snapshot completo. Junto con la propiedad explícita de tareas, la liveness de procesos, el historial de herramientas y la evidencia de finalización, este contrato de deltas y snapshots aporta los datos necesarios para decidir el siguiente paso. El repositorio no registra un benchmark de rendimiento para esta ruta de sincronización.
