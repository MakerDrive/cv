Agent Pool проверяет filesystem boundaries, используемые делегированием и memory tools. Запрошенный working directory и каждый дополнительный каталог разрешаются до запуска, затем отклоняются при совпадении с настроенными системными roots. Итоговый workspace scope явно передаётся воркеру в prompt.

Для создания skill действует более узкое правило. Имена с path separators или `..` отклоняются до построения пути файла. Пути встроенных policies разрешаются и принимаются только внутри каталога policies пакета. Эти проверки покрывают реализованные операции skills и policies, описанные в документации.

Process isolation задаётся через назначенный `cwd`, явные included directories, permission modes провайдера и lifecycle process group. Node.js-реализация не собирает полный environment заново для каждого child process. У этих контролей разные ответственности, поэтому их нельзя сводить к одному неопределённому sandbox.
