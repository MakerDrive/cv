Agent Pool MCP направляет ограниченное задание на проверку через настроенную resource group `review`. Оркестратор вызывает `delegate_task_readonly`, получает идентификатор задачи и забирает готовый отчёт с помощью `get_task_result`.

В отчёте проверяющий агент перечисляет проблемы, риски и предлагаемые изменения. Оркестратор сверяет их с текущими файлами и результатами проверок, затем решает, что менять и выполнены ли критерии приёмки. Для проверки можно использовать любую модель и платформу, настроенную для этой resource group.
