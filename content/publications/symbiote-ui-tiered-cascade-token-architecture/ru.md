Я перевёл контракт Cascade Theme в Symbiote UI с плоского списка пользовательских свойств на явные уровни токенов. T0 хранит исходные настройки, T1 формирует опорные шкалы, T2 задаёт семантические системные роли, а T3 связывает слоты компонентов с этими ролями. Доменные палитры для графов и других инструментов оформлены отдельными блоками расширения.

Направление алиасов проверяется по цепочке `component -> system -> reference -> source`. Стили компонентов используют роли T2 и не обращаются напрямую к опорным шкалам или исходным настройкам. Поэтому системные роли T2 принадлежат Symbiote UI, в том числе когда Agent Portal задаёт собственные значения по умолчанию.

Каскад вычисляется в CSS. Относительные цвета OKLCH, `color-mix()`, `light-dark()`, зарегистрированные пользовательские свойства и нативный каскад формируют активную тему. JavaScript записывает исходные настройки, сохраняет набор и применяет выбранную область. Каталог токенов и манифест обнаружения публикуют ту же уровневую модель для агентов.
