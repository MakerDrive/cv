Agent Pool хранит для каждой делегированной задачи ограниченный tail stderr и объединяет его с live events, прошедшим временем, идентификатором процесса и итоговым exit result. Состояние запущенной задачи можно проверить, не передавая в контекст агента неограниченный process log.

Diagnostic formatter считает сигнатуры rate limit, включая `429` и `RESOURCE_EXHAUSTED`. Если провайдер печатает `retryDelay` или `retryDelayMs`, значение выводится вместе со статусом задачи. Остальной stderr сокращается до короткого фрагмента с полезной диагностикой. Parser сообщает только то, что выдал провайдер, и не выводит состояние квоты из отсутствующих данных.

Liveness проверяется по PID дочернего процесса сигналом `0`: процесс не завершается, проверяется лишь его существование. Для завершённых задач сохраняются структурированный результат и ошибки. В репозитории нет измерений memory overhead или изоляции event loop, поэтому диагностический контракт ограничен этими реализованными границами процессов и результатов.
