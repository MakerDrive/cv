The public PhotoPizza repository describes a complete buildable turntable system. It includes laser-cut drawings for several table sizes, stepper-motor mechanics, and a separate control-unit enclosure.

The documented control unit uses an ESP32, a stepper-driver board and driver, a relay, an IR receiver, a display, cooling, and a camera-sync connection. Espruino firmware links those components to frame count, speed, pause, delay, direction, calibration, still-photo sequences, and continuous rotation for video.

This architecture let the same open-source equipment support product photo-360, video, and photogrammetric scanning. Builders can select a table size and assemble the mechanical and controller layers from the published drawings, firmware, and component lists.
