Symbiote Node фиксирует переход, в ходе которого я разделил свою RND-PRO-линию Symbiote на отдельные проекты. Symbiote UI получил Web Components, темы, метаданные провайдеров, схемы и контракты WebMCP. В Symbiote Engine перешли исполнение графов, обработчики, средства сохранения и команды CLI для среды выполнения.

Оставшийся пакет `symbiote-node` служит завершающим миграционным фасадом. Его публичные точки входа делегируют работу разделённым пакетам, чтобы существующие потребители могли поэтапно перенести импорты. Новые интерфейсные и исполнительные возможности реализуются непосредственно в Symbiote UI или Symbiote Engine.

Symbiote.js остаётся внешней зависимостью и референсом для этой проектной линии. Здесь описаны пакетный workspace RND-PRO, разделение ответственности и миграционная поверхность.
