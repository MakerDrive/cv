Agent Portal funciona en modos standalone, client y master. Un nodo standalone administra sus servidores MCP locales. El client se conecta al master por WebSocket y comparte sus herramientas; el master las combina con sus propios servidores dentro del portal.

En cada equipo, las ventanas del IDE se conectan mediante proxies stdio a un backend singleton desacoplado. El smart gateway ofrece `discover_tools` para buscar herramientas públicas, `call_tool` para validar y ejecutar una llamada seleccionada, y `get_portal_status` para consultar los servidores públicos y el estado del runtime. Agent Pool gestiona la orquestación de chats dentro del portal. Si se corta WebSocket, el client informa de la pérdida y realiza un número limitado de intentos de reconexión.
