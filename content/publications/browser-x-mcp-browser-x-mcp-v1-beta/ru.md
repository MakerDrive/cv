Browser X MCP `1.0.0-beta.1` оформил первый публичный browser server этой линейки. Он использует Playwright для управления Chromium page и открывает операции через stdio MCP-сервер.

В базовый набор инструментов (beta tool surface) входят запуск браузера, навигация, извлечение структуры страницы (structured virtual canvas), ввод текста, скролл, список элементов, детали цели, атомарные и пакетные действия (batch actions), скриншоты и выполнение кода в контексте страницы. Виртуальный холст (virtual canvas) получает данные интерактивных элементов из актуального DOM и назначает идентификаторы с координатами, которые затем используют действия.

Версия пакета, зависимость Playwright, зарегистрированные инструменты MCP и реализованные обработчики определяют этот экспериментальный beta-релиз. Репозиторий не гарантирует строгого соответствия стандартам W3C, изоляции процессов отдельных браузерных инстансов или политики отключения CDP. Такие свойства нельзя выводить из самой метки релиза.
