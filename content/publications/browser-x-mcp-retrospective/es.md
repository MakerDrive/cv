Browser X MCP fue un experimento público temprano de automatización del navegador: un servidor MCP sobre stdio basado en Playwright. El repositorio beta implementa inicio y navegación del navegador, extracción estructurada de la página, entrada en formularios, scroll, inspección de elementos, acciones atómicas, capturas y evaluación dentro del contexto de la página.

Su representación principal es el virtual canvas, una descripción estructurada del DOM activo con identificadores estables y coordenadas para interactuar. El agente puede listar elementos de navegación, pedir el detalle de un objetivo y ejecutar la acción resultante. Las capturas siguen disponibles como evidencia separada y para comparar tamaños. El paquete usa transporte stdio y no implementa un protocolo WebSocket genérico para el contexto.

El código también documenta los límites del prototipo. La instancia del navegador vive en el proceso local, las acciones requieren una página activa y los fallos se devuelven como errores MCP. Browser X aporta evidencia de la exploración inicial de la interfaz. En Agent Portal actual, el acceso al navegador es un límite configurable de herramientas; la beta no se presenta como la totalidad del stack moderno de control.
