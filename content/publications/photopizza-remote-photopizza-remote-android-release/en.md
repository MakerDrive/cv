PhotoPizza Remote adds a native Android control surface to the original browser-based interface. The app connects to the turntable controller over local Wi-Fi and WebSocket, then exposes rotation direction, frame count, speed, pause, delay, start and stop controls, and saved configuration.

The public repository includes the Android source, build instructions, and a prebuilt `PhotoPizza.apk`. The same repository keeps the original browser UI, and both clients use the existing controller contract.
