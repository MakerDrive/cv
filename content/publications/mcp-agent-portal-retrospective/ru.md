`mcp-agent-portal` упаковывает control plane Agent Portal в MCP-сервер. Это публичный шлюз для чатов и операций оркестрации портала, а также выбранных инструментов дочерних серверов. Низкоуровневые операции Agent Pool остаются внутри runtime продукта, поэтому внешний клиент получает меньший контракт с явной границей ответственности.

Шлюз публикует схемы инструментов через MCP discovery и проверяет вызовы по тому же registry. В публичную поверхность входят создание и продолжение чатов, получение результата задачи, статус оркестрации и development map. Субагенты могут подключаться к Streamable HTTP endpoint; для IDE сохраняется stdio-вход и мост к singleton backend.

У вызова инструмента есть именованные параметры, объявленная форма результата и стабильная граница контекста. Реализация выражает этот контракт через JavaScript-описания инструментов, MCP request handlers и чёткое разделение публичных gateway tools и внутреннего execution layer. Отдельной Python-абстракции `Agent` в репозитории нет.
