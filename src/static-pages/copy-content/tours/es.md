# CV Show

## identity / Quién soy
Hola, soy Vladimir Matiasevich, Lead R&D Engineer. Llevo más de quince años creando productos de software, sistemas de medios y hardware. Hoy combino esa experiencia en ciclos de automatización controlados.

## problem / El problema que resuelvo
Trabajo con procesos que requieren una secuencia de acciones verificables. El sistema debe observar su estado, elegir la siguiente acción, ejecutarla y comprobar el resultado. Diseño ese ciclo de extremo a extremo, desde la interfaz y el backend hasta la automatización del navegador o un dispositivo físico.

## agent-portal / Agent Portal
Agent Portal es mi entorno de trabajo para ingeniería asistida por IA. Sus herramientas MCP reúnen el contexto del proyecto, construyen el grafo del código, coordinan la ejecución y operan el navegador y la terminal. Las transiciones, los criterios de finalización y la verificación forman parte del proceso.

## symbiote / La línea Symbiote
Symbiote desarrolla la misma idea como línea de producto. Workspace define un entorno adaptado a la tarea, UI aporta componentes reutilizables y Engine ejecuta grafos de procesos. Es mi dirección actual de I+D para sistemas que se componen alrededor de un trabajo concreto.

## museum-capture / Digitalización de museos
Otra parte de mi trabajo es la captura 3D de alta definición. Desarrollé tecnología y equipos para OBJET.art y ArtClub Digital Heritage, utilizados en el Hermitage, la Kunstkamera, otros museos y colecciones privadas. El software, la iluminación, la mecánica y el trabajo de campo formaban un solo sistema.

## method / Cómo trabajo
Suelo comenzar estudiando el dominio y observando el proceso real. Después fijo la arquitectura, construyo un prototipo y lo pruebo en condiciones de trabajo. La revisión, la documentación del contexto y la responsabilidad explícita ayudan a llevar un experimento hasta la operación.

## pulse / Registro público de decisiones
La sección Pulse reúne notas de versiones, experimentos y decisiones de ingeniería de estos proyectos. Cada entrada conecta el estado del producto con las razones, las restricciones y el resultado de una iteración concreta.
