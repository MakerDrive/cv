Agent Portal работает в режимах standalone, client и master. Узел standalone владеет локальными MCP-серверами. Client подключается к master по WebSocket и передаёт ему свои инструменты; master объединяет их со своими серверами в общем интерфейсе портала.

На каждом компьютере окна IDE подключаются через stdio-прокси к отдельному singleton backend. Smart gateway предоставляет `discover_tools` для поиска публичных инструментов, `call_tool` для проверки и вызова выбранного инструмента, а `get_portal_status` — для просмотра публичных серверов и состояния runtime. Agent Pool обслуживает оркестрацию чатов внутри портала. При разрыве WebSocket client сообщает об этом и предпринимает ограниченное число попыток восстановить соединение.
