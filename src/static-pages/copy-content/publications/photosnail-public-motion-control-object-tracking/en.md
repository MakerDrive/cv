PhotoSnail was an open motorized camera-slider prototype for time-lapse and video. Automatic object tracking appeared in the project description as part of the intended system, alongside an idea for partial 360-degree capture.

The public project page describes a system still in development. Its implemented path moves the carriage along the rails with configurable distance, frame count, direction, acceleration, and shutter pause. Automatic object tracking remained a design goal; the page does not describe an operating tracking feature.
