Browser X MCP `1.0.0-beta.1` оформил первый публичный browser server этой линейки. Он использует Playwright для управления Chromium page и открывает операции через stdio MCP-сервер.

В beta tool surface входят запуск браузера, навигация, извлечение structured virtual canvas, ввод текста, scroll, список элементов, детали цели, атомарные и batch actions, screenshots и выполнение кода в page context. Virtual canvas получает данные интерактивных элементов из актуального DOM и назначает идентификаторы с координатами, которые затем используют действия.

Версия пакета, зависимость Playwright, зарегистрированные MCP tools и реализованные handlers определяют этот экспериментальный beta-релиз. Репозиторий не подтверждает строгого соответствия W3C, process isolation отдельного browser instance или политики отключения CDP. Такие свойства нельзя выводить из самого release label.
