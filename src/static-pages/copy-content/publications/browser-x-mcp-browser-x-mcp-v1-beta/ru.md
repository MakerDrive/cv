Browser X MCP `1.0.0-beta.1` представил браузерный сервер на Playwright с интерфейсом MCP stdio. Сервер запускает Chromium и предоставляет инструменты для навигации, изучения страницы, взаимодействия с ней и создания снимков экрана.

Виртуальный холст считывает интерактивные элементы из DOM текущей страницы и назначает им идентификаторы и координаты для последующих действий. В beta также доступны ввод текста, прокрутка, просмотр сведений об элементах, одиночные и пакетные действия, а также выполнение кода в контексте страницы.
