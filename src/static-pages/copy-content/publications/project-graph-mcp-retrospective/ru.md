Project Graph MCP - слой code intelligence, который я выделил в самостоятельный stdio MCP-сервер и npm-пакет. Он строит skeleton проекта по структуре исходников и предоставляет сфокусированные операции для зависимостей, usages, документации, compact code и анализа качества.

JavaScript анализируется vendored-парсером Acorn. Для TypeScript, Python и Go есть отдельные структурные parsers, включая regex-пути там, где полный AST не используется. Парсинг отделён от построения графа, поэтому одни структурные данные поддерживают MCP-инструменты и explorer в Agent Portal.

Compact mode сохраняет идентификаторы и сокращает форматирование, а `.ctx`-файлы хранят контракты документации, которые можно сверять с сигнатурами исходников или встраивать как JSDoc. Пакет также выдаёт skeleton и загружает focus zone. Эти пути реализованы на JavaScript; эквивалентного pipeline на Python или SWC и benchmark результата сжатия в репозитории нет.
