Compact Code Mode разделяет исполняемый source и документацию, необходимую для его восстановления и проверки. Project Graph MCP может компактизировать JavaScript с сохранением идентификаторов, а структурные и поясняющие контракты хранить в `.ctx` и `.ctx.md`.

Пакет предоставляет операции compact и beautify, генерацию context docs, добавление и удаление JSDoc, просмотр активного mode и валидацию pipeline. Validator сравнивает экспортируемые функции и сигнатуры с context contract и сообщает об отсутствующих или устаревших записях. Migration также проверяет состояние репозитория до перезаписи проекта.

Реализованная модель объединяет compact source, внешние context docs, двунаправленный JSDoc tooling и сверку контрактов с AST. Static type checking остаётся отдельной операцией. В репозитории нет воспроизводимого token, processor или runtime benchmark для этого режима.
