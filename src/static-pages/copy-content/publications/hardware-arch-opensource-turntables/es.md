El repositorio público PhotoPizza describe un sistema completo de plataforma giratoria que se puede construir. Incluye planos para corte láser de varios tamaños, mecánica con motor paso a paso y una carcasa separada para la unidad de control.

La unidad documentada usa ESP32, placa y driver del motor paso a paso, relé, receptor infrarrojo, pantalla, refrigeración y conexión de sincronización con la cámara. El firmware Espruino vincula esos componentes con número de fotogramas, velocidad, pausa, retardo, dirección, calibración, secuencias fotográficas y rotación continua para video.

La arquitectura permite usar el mismo equipo open-source para foto-360 de producto, video y escaneo fotogramétrico. Cada persona puede elegir el tamaño de la plataforma y montar la mecánica y el controlador a partir de los planos, firmware y listas de componentes publicados.
