Agent Portal стал публичной точкой входа в мою линейку агентных инструментов. Одна MCP-конфигурация открывает операции портала и выбранные дочерние инструменты. Execution runtime остаётся за этой границей, а dashboard показывает чаты, workflows, структуру проекта, состояние задач и live-диагностику из общего backend.

Для нескольких окон IDE используется detached singleton backend. Каждый локальный клиент запускается через stdio и подключается к backend по WebSocket; backend владеет дочерними MCP-процессами и общим состоянием портала. Режимы standalone, client и master распространяют тот же контракт на локальные и удалённые наборы инструментов.

Работа над StateGraph добавила версионированные операции. При реконнекте браузер с известной версией получает пропущенные patches, пока они доступны; устаревшему клиенту отправляется полный snapshot. Вместе с явным владением задачами, liveness процессов, историей вызовов и доказательством завершения этот delta-and-snapshot контракт даёт оператору факты для выбора следующего действия. В репозитории нет performance benchmark для этого пути синхронизации.
