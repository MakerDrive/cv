Browser X beta хранит Playwright browser и page в локальном состоянии процесса. Перед повторным использованием существующего instance `start_browser` выполняет простое выражение на странице. Если probe завершается ошибкой, сохранённый instance очищается и браузер можно запустить заново.

Browser actions требуют активной page. Navigation, extraction, input, clicks и evaluation при её отсутствии возвращают явную ошибку с указанием запустить браузер. Реализованная граница восстановления состоит из обнаружения мёртвого instance, его удаления и повторного создания browser state вызывающей стороной.

В репозитории нет точного ответа `Context Lost`, автоматической обработки death signal, OOM-specific evidence или системы восстановления cookies и local storage. После потери процесса состояние страницы не восстанавливается. Агенту нужно снова открыть target и получить актуальный DOM перед продолжением.
