Browser X MCP был ранним публичным экспериментом по браузерной автоматизации: MCP-сервер на базе Playwright со stdio-транспортом. В beta-репозитории реализованы запуск браузера и навигация, структурное извлечение страницы, ввод в формы, scroll, инспекция элементов, атомарные действия, screenshots и выполнение кода в контексте страницы.

Главное представление проекта - virtual canvas: структурированное описание актуального DOM со стабильными идентификаторами элементов и координатами для взаимодействия. Агент может получить список навигационных элементов, запросить детали одной цели и выполнить сформированное действие. Screenshot остаётся отдельным источником evidence и используется для сравнения размера. Пакет работает через stdio и не реализует универсальный защищённый WebSocket-протокол контекста.

Код фиксирует и ограничения прототипа. Browser instance живёт в локальном процессе, действия требуют активной страницы, а ошибки возвращаются через MCP. Поэтому Browser X служит доказательством ранней проработки интерфейса. Современный Agent Portal рассматривает браузерный доступ как настраиваемую границу инструментов, не выдавая beta за весь текущий browser-control stack.
