Agent Pool MCP - execution runtime многоагентных процессов Agent Portal. Делегирование запускает CLI-воркер и сразу возвращает идентификатор задачи. Вызывающая сторона может читать live events, ограниченную stderr-диагностику, состояние PID и итоговый результат или отменить работу, не удерживая исходный запрос открытым.

Runtime содержит адаптеры для нескольких CLI-провайдеров и сохраняет владение задачей в process management, resource groups и выдаче результатов. Последовательные pipelines хранят определения в team memory, а состояние запуска - отдельно. Шаг может завершиться, отправить структурированное сообщение или вернуть работу на предыдущий этап с обратной связью. Scheduled tasks выполняет detached daemon с parser пяти полей cron.

Agent Pool реализован на Node.js с файловым состоянием запусков; отдельного runtime на Python или LangGraph в нём нет. Cross-model review остаётся одним из доступных workflow, а решение о приёмке и архитектуре принадлежит оркестратору. Так исполнение процессов остаётся отделённым от решения control plane, которое закрывает задачу.
