Agent Pool MCP es el runtime de ejecución que sostiene los workflows multiagente de Agent Portal. Una delegación inicia un worker de CLI y devuelve de inmediato un identificador de tarea. El caller puede consultar eventos en vivo, diagnósticos acotados de stderr, estado del PID y resultado final, o cancelar el trabajo sin mantener abierta la solicitud original.

El runtime contiene adaptadores para varios proveedores de CLI y conserva la propiedad de la tarea en la gestión de procesos, los resource groups y la consulta de resultados. Los pipelines secuenciales guardan sus definiciones en team memory y mantienen aparte el estado de cada ejecución. Un paso puede completarse, enviar mensajes estructurados o devolver el trabajo a una etapa anterior con feedback. Un daemon desacoplado ejecuta las tareas programadas con un parser cron de cinco campos.

Agent Pool está implementado en Node.js con estado de ejecución basado en archivos; no contiene un runtime separado en Python o LangGraph. Cross-model review sigue disponible como workflow, mientras que la aceptación y las decisiones de arquitectura pertenecen al orquestador. Así, la ejecución de procesos queda separada de la decisión del plano de control que cierra una tarea.
