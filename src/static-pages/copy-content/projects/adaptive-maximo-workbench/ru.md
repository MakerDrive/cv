:::article-block demo-alpha
Adaptive Maximo Workbench — конфигурация Demo / Alpha для проверки Symbiote Workspace в предметной области обслуживания оборудования. Она показывает архитектуру рабочей среды; подключение производственной системы Maximo выполняется как отдельная интеграция.

:::article-block work-order-demo
Подтверждённый demo-путь работает в read-only режиме: открыть заявку, показать связанное оборудование и проверить список объявленных действий.

:::article-block work-orders
Поверхность заявок показывает очередь, статус, приоритет и связанный рабочий контекст в одном месте.

:::article-block asset-context
Контекст оборудования и локации связан с выбранной заявкой, поэтому человек и агент видят одну актуальную информацию.

:::article-block agentic-eam-demo
Agentic EAM Demo 1 показывает, как агент собирает рабочее пространство под конкретную задачу, а затем объясняет созданный интерфейс.

:::article-block xr-eam-example
XR EAM Example развивает ту же идею в пространственном интерфейсе, где связанный с задачей трёхмерный объект можно взять, повернуть и рассмотреть.

:::article-block safe-actions
Интерфейс объявляет действия, доступные в текущем состоянии. Операции, способные изменить внешнюю систему, недоступны в публичном demo.

:::article-block integration-boundary
Производственные данные, авторизация, права доступа и вызовы Maximo API принадлежат отдельному интеграционному слою host-приложения.
