Sistema UI reutilizable investigado para una restricción concreta: las interfaces deben ser componibles por software y comprensibles para agentes.

Cubre editores de grafos, diseños de paneles, árboles de recursos, barras de herramientas, catálogos de proveedores, metadatos estructurados de UI y contratos descubribles por herramientas para productos orientados a agentes. En la arquitectura Symbiote actual, esta biblioteca proporciona las primitivas visuales y los manifiestos de componentes (catálogo) para el orquestador Symbiote Workspace, actuando como los bloques de construcción a partir de los cuales los agentes de IA ensamblan dinámicamente entornos adaptativos.
