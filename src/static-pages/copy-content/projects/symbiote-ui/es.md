Sistema UI reutilizable investigado para una restricción concreta: las interfaces deben ser componibles por software y comprensibles para agentes.

Cubre editores de grafos, layouts de paneles, árboles de recursos, barras de herramientas, catálogos de proveedores, structured UI metadata y contratos descubribles por herramientas para productos orientados a agentes. En la línea Symbiote actual, UI trabaja con Workspace como superficie de producto y Engine como capa ejecutable de I+D.
