Переиспользуемая UI-система, построенная вокруг конкретного ограничения: интерфейсы должны быть компонуемыми программно и понятными для агентов.

Она покрывает редакторы графов, панельные раскладки, деревья ресурсов, панели инструментов, каталоги провайдеров, structured UI metadata и tool-discoverable контракты для продуктов, ориентированных на агентов. В актуальной Symbiote-связке UI работает вместе с Workspace как продуктовым интерфейсом и Engine как исполняемым R&D-слоем.
