:::article-block browser-fact
Este es un contexto de ingeniería compacto y estructurado: el foco I+D es context engineering, GraphRAG-style retrieval, compresión de contexto y comprensión del proyecto. Un modelo más rápido/barato puede analizar la estructura, producir una representación de grafo y dar al agente la parte relevante del proyecto para el paso actual. Los hechos verificables de pruebas en navegador forman una capa separada dentro de ese mapa enfocado.
