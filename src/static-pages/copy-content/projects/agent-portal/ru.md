Проект отвечает на практический R&D-вопрос: как использовать несколько ИИ-агентов в разработке и не терять контекст, владение задачами, проверяемость и контроль.

Среда объединяет долговременную проектную память, context engineering, RAG-style context retrieval, маршрутизацию моделей, tool use, оркестрацию задач и браузерные операции в один рабочий интерфейс для проверяемой разработки с ИИ.

Один из фокусов — оптимизация ресурсов: задачи распределяются между агентами с разными уровнями моделей. Простую и разведочную работу выполняют быстрые модели, а сложные решения принимают сильные модели на основе сжатого проектного контекста.

:::article-block human-decision
Текущая R&D-линия — loop engineering: проведение агентов по полному циклу разработки (взять задачу, написать код в изолированной ветке, доказать работоспособность, проверить и объединить). Процесс включает evals, guardrails и human-in-the-loop контроль при нештатных ситуациях.

Agent Portal построен на наборе MCP-серверов моего авторства, которые координируются open-source контуром управления (`mcp-agent-portal`). Этот контур оркестрирует исполнение агентов (Agent Pool), графовую кодовую аналитику (Project Graph), а также браузерную и терминальную автоматизацию, предоставляя чистый tool-use/function-calling контракт между агентами и продуктовой средой.

Вектор развития проекта направлен на отказ от монолитного приложения в пользу портативных конфигураций (Workspace-as-Config). В целевой архитектуре Agent Portal становится тонким хостом (предоставляющим чат, авторизацию и маршрутизацию моделей), а сам интерфейс и рабочие процессы динамически собираются агентами с помощью Symbiote Workspace.
