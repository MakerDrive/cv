Проект отвечает на практический R&D-вопрос: как использовать несколько ИИ-агентов в разработке и не терять контекст, владение задачами, проверяемость и контроль.

Среда объединяет долговременную проектную память, context engineering, RAG-style context retrieval, маршрутизацию моделей, tool use, оркестрацию задач и браузерные операции в один рабочий интерфейс для проверяемой разработки с ИИ.

Один из фокусов — оптимизация ресурсов: задачи распределяются между агентами с разными уровнями моделей. Простую и разведочную работу выполняют быстрые модели, а сложные решения принимают сильные модели на основе сжатого проектного контекста.

Текущая R&D-линия — loop engineering для автономной разработки: проведение кодинг-агентов по всему циклу — взять задачу, работать в изолированной ветке, доказать, что работа выполнена, затем проверить и объединить результат — с evals, guardrails, observability и human-in-the-loop контролем, когда процесс не может безопасно продолжать работу.

Agent Portal построен на наборе MCP-серверов моего авторства, каждый из которых работает сам по себе и собирается в продукт: исполнение агентов (Agent Pool), графовая кодовая аналитика и retrieval (Project Graph), а также браузерная, контекстная и терминальная автоматизация.
