:::article-block intro
Symbiote Workspace — универсальная среда для работы над конкретной задачей. Агент превращает намерение пользователя в интерфейс, собранный из объявленных компоновок, панелей, модулей, действий и связей.

:::article-block portable-config
Результат сохраняется как переносимая исполняемая конфигурация. Её можно проверить, сохранить, обновить во время работы и снова открыть в совместимом host-приложении.

:::article-block config-artifact
Переносимый артефакт описывает layout, модули, действия, связи, состояние темы, runtime slots и требования к host, но не включает учётные данные и идентификацию пользователя.

:::article-block config-flow
Путь сборки задан явно: намерение превращается в конфигурацию, конфигурация проходит валидацию, а host монтирует готовое рабочее пространство. Symbiote UI поставляет переиспользуемые визуальные блоки, Symbiote Engine — блоки исполнения.

:::article-block agent-portal
Agent Portal оформляется как конфигурация Workspace для инженерной работы с агентами. Проект находится в активной разработке.

:::article-block video-studio
Symbiote Video Studio тоже переходит к этой модели конфигурации; работающее видео-ядро и alpha-статус рабочей среды обозначаются отдельно.

:::article-block host-examples
Agent Portal и Symbiote Video Studio — два совместимых host-примера с разными продуктовыми процессами и границами зрелости.

:::article-block host-boundary
Авторизация, секреты, маршрутизация моделей, хранение, идентификация и пользовательские данные остаются ответственностью host-приложения. Я развиваю Workspace как переносимый слой сборки между возможностями host и переиспользуемыми библиотеками UI и исполнения.
