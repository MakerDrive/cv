Рабочее пространство для координации интерфейсов, собираемых агентами. Управляет состоянием процессов, структурой графов, сериализацией и передачей артефактов в продуктовых пайплайнах.

В актуальной Symbiote-линии Workspace выступает рабочим продуктовым интерфейсом: он связывает интерфейсный слой Symbiote UI и исполняемые эксперименты Symbiote Engine; Symbiote Node показывает раннюю пакетную организацию этой линии.
