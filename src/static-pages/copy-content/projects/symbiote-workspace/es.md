:::article-block intro
Symbiote Workspace es un entorno universal para trabajo orientado a una tarea concreta. Un agente convierte la intención del usuario en una interfaz compuesta por layouts, paneles, módulos, acciones y conexiones declaradas.

:::article-block portable-config
El resultado se conserva como una configuración ejecutable y portátil.

:::article-block config-flow
El recorrido de construcción es explícito: la intención se convierte en configuración, la configuración se valida y el host monta el workspace resultante. Symbiote UI aporta bloques visuales reutilizables; Symbiote Engine aporta bloques reutilizables de ejecución.

:::article-block config-artifact
Puede validarse, guardarse, actualizarse mientras el workspace está activo y abrirse de nuevo en una aplicación host compatible. El artefacto portátil registra layout, módulos, acciones, conexiones, estado del tema, runtime slots y requisitos del host sin incorporar credenciales ni identidad de usuario.

:::article-block agent-portal
Agent Portal se está preparando como una configuración de Workspace para ingeniería asistida por agentes. Su estado actual sigue siendo desarrollo activo.

:::article-block video-studio
Symbiote Video Studio también avanza hacia este modelo de configuración, mientras el núcleo de video operativo y el workspace alpha conservan etiquetas de madurez separadas. Agent Portal y Symbiote Video Studio son dos ejemplos compatibles con hosts, con procesos de producto y límites de madurez distintos.

:::article-block host-examples
La autenticación, los secretos, el enrutamiento de modelos, el almacenamiento, la identidad y los datos de usuario siguen siendo responsabilidades del host.

:::article-block host-boundary
Desarrollo Workspace como la capa portátil de construcción entre esas capacidades y las bibliotecas reutilizables de UI y ejecución.
